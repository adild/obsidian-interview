The **Builder Design Pattern** in Java is a **creational design pattern** used to construct complex objects **step-by-step**. It separates the construction of a complex object from its representation, allowing the same construction process to create different representations.

---
## ✅ Why Use Builder Pattern?
- To **create immutable objects** with many optional parameters
- To **avoid telescoping constructors** (constructors with many parameters)
- To **make object creation readable and flexible**

Student class
```
package com.system.design.lld.builder;  
  
public class Student {  
  
    private String name;  
    private int age;  
    private int classNumber;  
    private int rollNumber;  
    private int dob;  
  
    public Student(StudentBuilder sb) {  
        this.name = sb.getName();  
        this.age = sb.getAge();  
        this.classNumber = sb.getClassNumber();  
        this.rollNumber = sb.getRollNumber();  
        this.dob = sb.getDob();  
    }  
  
    @Override  
    public String toString() {  
        return "Student{" +  
                "name='" + name + '\'' +  
                ", age=" + age +  
                ", classNumber=" + classNumber +  
                ", rollNumber=" + rollNumber +  
                ", dob=" + dob +  
                '}';  
    }  
```

StudentBuilder class
```
package com.system.design.lld.builder;  
  
public class StudentBuilder {  
  
    private String name;  
    private int age;  
    private int classNumber;  
    private int rollNumber;  
    private int dob;  
  
    public StudentBuilder setName(String name) {  
        this.name = name;  
        return this;  
    }  
  
    public StudentBuilder setAge(int age) {  
        this.age = age;  
        return this;  
    }  
  
    public StudentBuilder setClassNumber(int classNumber) {  
        this.classNumber = classNumber;  
        return this;  
    }  
  
    public StudentBuilder setRollNumber(int rollNumber) {  
        this.rollNumber = rollNumber;  
        return this;  
    }  
  
    public StudentBuilder setDob(int dob) {  
        this.dob = dob;  
        return this;  
    }  
  
    public String getName() {  
        return name;  
    }  
  
    public int getAge() {  
        return age;  
    }  
  
    public int getClassNumber() {  
        return classNumber;  
    }  
  
    public int getRollNumber() {  
        return rollNumber;  
    }  
  
    public int getDob() {  
        return dob;  
    }  
  
    public Student build() {  
        return new Student(this);  
    }  
}
```

Main class
```
package com.system.design.lld.builder;  
  
public class Main {  
  
    public static void main(String[] args) {  
        Student abc = new StudentBuilder()  
                .setName("abc")  
                .setAge(12)  
                .setDob(34)  
                .build();  
  
        System.out.println(abc);  
    }  
}
```
