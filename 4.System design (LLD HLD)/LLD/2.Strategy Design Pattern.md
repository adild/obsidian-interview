## Strategy Design Pattern in Java

The **Strategy Design Pattern** is a behavioral design pattern where you **define multiple ways (strategies) of doing something and make them interchangeable**.

In simple words:

> **Instead of putting many `if-else` conditions in one class, create separate classes for each behavior and choose the behavior you need at runtime.**

---

### 1. The problem

Suppose you're building a payment system:

```
class PaymentService {

    public void pay(String paymentType) {

        if (paymentType.equals("UPI")) {
            // UPI payment logic

        } else if (paymentType.equals("CARD")) {
            // Card payment logic

        } else if (paymentType.equals("NET_BANKING")) {
            // Net banking logic
        }
    }
}
```

This works, but imagine you eventually have:

- UPI
- Credit Card
- Debit Card
- PayPal
- Apple Pay
- Google Pay
- Wallet

Your class becomes a huge collection of `if-else` statements.

That's where **Strategy Pattern** helps.

---

# 2. Create a Strategy interface

Define what every payment strategy must do:

```
public interface PaymentStrategy {

    void pay(double amount);
}
```

This is our **common contract**.

---

# 3. Create different strategies

### UPI Strategy

```
public class UpiPaymentStrategy implements PaymentStrategy {

    @Override
    public void pay(double amount) {
        System.out.println("Paying ₹" + amount + " using UPI");
    }
}
```

### Card Strategy

```
public class CardPaymentStrategy implements PaymentStrategy {

    @Override
    public void pay(double amount) {
        System.out.println("Paying ₹" + amount + " using Card");
    }
}
```

### Net Banking Strategy

```
public class NetBankingStrategy implements PaymentStrategy {

    @Override
    public void pay(double amount) {
        System.out.println("Paying ₹" + amount + " using Net Banking");
    }
}
```

Now each class contains **one specific algorithm/behavior**.

---

# 4. Create the Context

The **Context** is the class that uses the strategy.

```
public class PaymentService {

    private PaymentStrategy paymentStrategy;

    public PaymentService(PaymentStrategy paymentStrategy) {
        this.paymentStrategy = paymentStrategy;
    }

    public void makePayment(double amount) {
        paymentStrategy.pay(amount);
    }
}
```

Notice something important:

`PaymentService` doesn't know **how** UPI, Card, or Net Banking works.

It only knows:

```
paymentStrategy.pay(amount);
```

---

# 5. Using it

```
public class Main {

    public static void main(String[] args) {

        PaymentStrategy strategy =
                new UpiPaymentStrategy();

        PaymentService paymentService =
                new PaymentService(strategy);

        paymentService.makePayment(500);
    }
}
```

Output:

```
Paying ₹500.0 using UPI
```

Want Card?

```
PaymentStrategy strategy =
        new CardPaymentStrategy();

PaymentService paymentService =
        new PaymentService(strategy);

paymentService.makePayment(500);
```

Output:

```
Paying ₹500.0 using Card
```

The `PaymentService` itself doesn't change.
