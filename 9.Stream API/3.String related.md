convert String to Character Stream.
```
String abc= "java";  
Stream<Character> characterStream = abc.chars().mapToObj(e -> (char) e);
```

Now we can perform intermediate and terminal operations.

- Given a String, find the first non-repeated character in it using Stream functions?
```
String abc= "java";  
Optional<Character> first1 = abc.chars().mapToObj(e -> (char) e)  
        .filter(e -> abc.indexOf(e) == abc.lastIndexOf(e))  
        .findFirst();  
System.out.println(first1.get());
```

Given a String, find the first repeated character in it using Stream functions?
```
String abc= "java";  
Optional<Character> first1 = abc.chars().mapToObj(e -> (char) e)  
        .filter(e -> abc.indexOf(e) != abc.lastIndexOf(e))  
        .findFirst();  
System.out.println(first1.get());
```
