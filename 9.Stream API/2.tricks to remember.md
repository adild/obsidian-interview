```
Stream<Integer> intStream = Stream.of(1, 2, 3, 4, 5);
```

flatMap - converts nested list to into single list
```
List<Integer> one = List.of(1, 1, 2, 3);  
List<Integer> two = List.of(1, 1, 2, 3);  
List<List<Integer>> three = List.of(one, two);  
System.out.println(three);  
List<Integer> list1 = three.stream().flatMap(List::stream).toList();  
System.out.println(list1);
```
