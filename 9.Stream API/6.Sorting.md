In Java Streams, you use **`sorted()`** to sort elements.

### 1. Natural ascending order

```
List<Integer> numbers = List.of(5, 2, 8, 1, 3);

List<Integer> result = numbers.stream()
        .sorted()
        .toList();

System.out.println(result);
```

Output:

```
[1, 2, 3, 5, 8]
```

`sorted()` uses the elements' **natural ordering**.

---

### 2. Descending order

Use `Comparator.reverseOrder()`:

```
List<Integer> result = numbers.stream()
        .sorted(Comparator.reverseOrder())
        .toList();

System.out.println(result);
```

Output:

```
[8, 5, 3, 2, 1]
```

---

### 3. Sort Strings

```
List<String> names = List.of("John", "Alice", "Bob", "David");

List<String> result = names.stream()
        .sorted()
        .toList();

System.out.println(result);
```

Output:

```
[Alice, Bob, David, John]
```

Descending:

```
List<String> result = names.stream()
        .sorted(Comparator.reverseOrder())
        .toList();
```

---

## 4. Sorting objects — very important

Suppose:

```
class Employee {
    String name;
    int salary;

    // constructor, getters...
}
```

You can sort by salary:

```
employees.stream()
        .sorted(Comparator.comparing(Employee::getSalary))
        .toList();
```

Ascending salary:

```
John   30000
Bob    40000
Alice  50000
```

Descending:

```
employees.stream()
        .sorted(Comparator.comparing(Employee::getSalary).reversed())
        .toList();
```

Result:

```
Alice  50000
Bob    40000
John   30000
```

---

## 5. Sort by multiple fields

This is where `Comparator` becomes really useful.

Suppose you want:

> Sort by salary, and if salary is the same, sort by name.

```
employees.stream()
        .sorted(
            Comparator.comparing(Employee::getSalary)
                      .thenComparing(Employee::getName)
        )
        .toList();
```

For example:

```
Bob    50000
Alice  50000
John   40000
David  40000
```

would become:

```
David  40000
John   40000
Alice  50000
Bob    50000
```

---

### The important methods to remember

```
.sorted()
```

→ natural ascending order

```
.sorted(Comparator.reverseOrder())
```

→ descending order

```
.sorted(Comparator.comparing(...))
```

→ sort objects based on a property

```
.sorted(Comparator.comparing(...).reversed())
```

→ descending based on a property

```
.sorted(Comparator.comparing(...).thenComparing(...))
```

→ sort by multiple properties

**One important point:** `sorted()` does not modify your original `List`. It creates a sorted stream, and `toList()` creates the resulting list.
