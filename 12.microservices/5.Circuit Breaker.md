A **Circuit Breaker** in Spring Boot is a **resilience pattern** used to prevent cascading failures when a service you're calling is **unavailable**, **slow**, or **failing repeatedly**.

Spring Boot supports Circuit Breaker through:
- **Resilience4j** (recommended)
- Hystrix (deprecated)
## 🧠 What Is a Circuit Breaker?
It works like a real electrical circuit breaker:
- When a service **fails repeatedly**, the circuit **opens** (blocks further calls)
- After a timeout, it goes to **half-open** (test if service recovered)
- If successful, it **closes** again (resumes traffic)
## 🔧 Step-by-Step: Implement Circuit Breaker with Resilience4j

### ✅ 1. Add Dependencies
#### `pom.xml`:
```
<dependencies>
    <!-- Resilience4j Circuit Breaker -->
    <dependency>
        <groupId>io.github.resilience4j</groupId>
        <artifactId>resilience4j-spring-boot3</artifactId>
    </dependency>

    <!-- Actuator for monitoring -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-actuator</artifactId>
    </dependency>
</dependencies>
```
Actuator dependency is used for checking health for the service. From health we will know which service is up or down.

### ✅ 2. Application Properties
```
resilience4j:
  circuitbreaker:
    instances:
      myService:
        registerHealthIndicator: true
        slidingWindowSize: 5
        minimumNumberOfCalls: 5
        failureRateThreshold: 50
        waitDurationInOpenState: 10s
        permittedNumberOfCallsInHalfOpenState: 2

management:
  endpoints:
    web:
      exposure:
        include: resilience4j.circuitbreakers, health, info
```
### ✅ 3. Use Circuit Breaker in Service
```
@Service
public class MyService {

    @CircuitBreaker(name = "myService", fallbackMethod = "fallback")
    public String callRemoteService() {
        // Simulate failure
        if (new Random().nextBoolean()) {
            throw new RuntimeException("Service failed");
        }
        return "Remote service response";
    }

    // Fallback method
    public String fallback(Throwable t) {
        return "Fallback response: Service is temporarily unavailable";
    }
}
```
@CircuitBreaker() annotation is used on the method where we are actually calling other microservice using feign client.
It takes 2 parameters: 
1. name - the service name which we will call
2. fallbackMethod - the method which will get execute if service is down, we need to create the method and provide the implementation.

### ✅ 5. Test It

`GET http://localhost:8080/test`

- Half the time, it will simulate a failure
- After 5 failures (per config), the circuit will **open**
- For 10 seconds, calls go directly to fallback without trying the real method
- After that, it tries again (half-open), and may close if successful
