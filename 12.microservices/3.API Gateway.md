add dependency ie api gateway.

application.properties -
```
server:
  port: 8080

spring:
  application:
    name: api-gateway

  cloud:
    gateway:
      routes:
        - id: user-service
          uri: http://localhost:8081
          predicates:
            - Path=/users/**
        - id: product-service
          uri: http://localhost:8082
          predicates:
            - Path=/products/**
```

id is the name of the service which will get called.
uri is the location of the service, basically the context path and port number where service is running.
predicates is the controllers where actual paths are there

This will:
Forward /users/** requests to the User Service (on port 8081)
Forward /products/** requests to the Product Service (on port 8082)

so where we call api gateway ie from localhost:8080 and use the id of the servie to be called then that service will get called -
GET http://localhost:8080/users/123      → Forwards to http://localhost:8081/users/123
GET http://localhost:8080/products/456   → Forwards to http://localhost:8082/products/456
