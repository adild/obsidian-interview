To implement **Eureka Service Discovery** in Spring Boot, you'll typically set up:
1. A **Eureka Server**
2. One or more **Eureka Clients** (i.e., microservices)
---
## 🧭 Overview
- **Eureka Server**: Central registry for service discovery.
- **Eureka Clients**: Microservices that register themselves and discover others via the server.

## ✅ Step 1: Create the Eureka Server
---
### 📦 Dependencies (`pom.xml`)
```
<dependencies>
    <dependency>
        <groupId>org.springframework.cloud</groupId>
        <artifactId>spring-cloud-starter-netflix-eureka-server</artifactId>
    </dependency>
</dependencies>
```
Above dependency is the dependency for the server, carefully look at the artifactId
### 🎯 Enable Eureka Server
In your main application class, @EnableEurekaServer:
```
@SpringBootApplication
@EnableEurekaServer
public class EurekaServerApplication {
    public static void main(String[] args) {
        SpringApplication.run(EurekaServerApplication.class, args);
    }
}
```

⚙️ `application.yml`
```
server:
  port: 8761

eureka:
  client:
    register-with-eureka: false
    fetch-registry: false
```

register-with-eureka: false
- **Preventing Self-Registration:** When operating a standalone Eureka Server (meaning it's not part of a cluster of multiple Eureka Servers), setting `register-with-eureka` to `false` prevents the Eureka Server itself from attempting to register as a client with its own registry. The Eureka Server is the registry, so it does not need to register with itself.
fetch-registry: false
- indicates that the application should not attempt to fetch the registry of available services from other Eureka servers.

## ✅ Step 2: Create a Eureka Client (e.g., User Service)
### 📦 Dependencies
```
<dependencies>
    <!-- Eureka Client -->
    <dependency>
        <groupId>org.springframework.cloud</groupId>
        <artifactId>spring-cloud-starter-netflix-eureka-client</artifactId>
    </dependency>
</dependencies>
```
Above dependency is the dependency for the client, carefully look at the artifactId
### 🎯 Enable Eureka Client
In your main application class, @EnableEurekaClient:
```
@SpringBootApplication
@EnableEurekaClient
public class UserServiceApplication {
    public static void main(String[] args) {
        SpringApplication.run(UserServiceApplication.class, args);
    }
}
```
`@EnableEurekaClient` is optional if you're using Spring Boot 2.1+ — discovery is auto-enabled when the dependency is on the classpath.

### ⚙️ `application.yml`
```
server:
  port: 8081

spring:
  application:
    name: user-service

eureka:
  client:
    service-url:
      defaultZone: http://localhost:8761/eureka
```
eureka.client.service-url.defaultZone: is for connecting to the eureka server where it is actually running on port 8761

## 📺 Eureka Dashboard
Visit `http://localhost:8761` to see registered services.
